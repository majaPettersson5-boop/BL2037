# Kurs: BL2037 - Bioinformatik

Detta repository innehåller allt material och alla inlämningar för kursen BL2037. 
Projektet är organiserat efter student för att tydligt visa vem som har gjort vad.

## Innehåll
Repositoryt är uppdelat i huvudmappar för varje student. Varje studentmapp innehåller följande struktur:

* `/data` – Rådata och filer som används i laborationerna.
* `/results` – Resultatfiler, loggar och utdata.
* `/software` – Script och programkod (t.ex. bash-script för sökningar).
* `/runs` – Information om körningar och parametrar.
